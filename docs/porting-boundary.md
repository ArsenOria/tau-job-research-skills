# What is open

This repository contains edited job-search instructions, a public Scout tool-reference snapshot, synthetic examples and offline validation/packaging helpers. The editorial starting points were Tau's existing job-search and job-application resource skills. No production prompts or service credentials are included.

The companion Scout repository contains independent local MCP tools, normalized vacancy data, a third-party Apify adapter and transparent baseline matching. The user supplies an Apify token; no Tau account, hosted proxy or shared key is required.

The closed Tau product retains its account/authentication flows, billing, production prompts and matching orchestration, worker queues, scheduling, LinkedIn sessions and browser profiles, application engine, outreach execution, customer records and service infrastructure.

Open-source users may modify these instructions and the published code under the license. The distinction from the full product is the scope we publish, not an unenforceable client-side job quota.
